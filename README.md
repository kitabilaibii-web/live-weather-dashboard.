# live-weather-dashboard.
A real-time weather dashboard built with HTML, CSS, JavaScript, and Fetch API to display dynamic, live weather updates based on city searches.
# Smart Weather Dashboard 🌤️

A responsive and dynamic web application that fetches live weather data using a third-party Weather API.

## 🚀 Features
- Live weather updates based on city search.
- Dynamic UI updates according to weather conditions.
- Fully responsive design for mobile and desktop view.

## 🛠️ Tech Stack
- HTML5 & CSS3 (Tailwind CSS)
- JavaScript (ES6+, Fetch API, Async/Await)
